# Zenawi Wallet — Stack web prototype

Open `/zenawi-stack/index.html` with the existing development server. The mobile application runtime is unchanged.

The standalone page includes mobile navigation, seven searchable modules, role-based onboarding, the Zeni fox guide, three simulated API responses, JSON downloads and local practice progress. `/zenawi-stack/prototypes.html` retains all ten design directions.

API examples are fixed fixtures, not live integrations. Progress is local to this browser. No form sends a message to a team.
